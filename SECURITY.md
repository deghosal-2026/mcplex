# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in MCPlex, please report it
privately. **Do not open a public GitHub issue.**

Email: deghosal (at) gmail.com

You should receive a response within 48 hours. If you do not, please
follow up to ensure the message was received.

## What to Include

- A description of the vulnerability
- Steps to reproduce it
- The affected version(s)
- Any potential impact you've identified

## Scope

This security policy covers the MCPlex server itself and its default
connectors. It does not cover the backend services that MCPlex proxies
to — those should be reported to their respective maintainers.

## Process

1. You report the issue via email
2. We acknowledge receipt within 48 hours
3. We investigate and develop a fix
4. We release a patched version
5. We disclose the vulnerability after the fix is released
